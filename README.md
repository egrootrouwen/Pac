# Pac Duo

Pac-Man voor twee spelers op één iPad. Open `index.html` in Safari (of AirDrop het naar de iPad en open het) — geen installatie nodig.

- Speler 1 (geel): d-pad linksonderaan of swipen op de linkerhelft
- Speler 2 (roze): d-pad rechtsonderaan of swipen op de rechterhelft
- Powerbol = jager; raak de andere speler om punten te stelen
- Doelscore instelbaar op het startscherm (150/300/500/800)
